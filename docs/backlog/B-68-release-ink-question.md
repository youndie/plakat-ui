# B-68 — On release a word is ink on ink for its first frames: keep it?

On every release of a press, the word is ink on ink, or cream on cream, for the first frames: Outlined, Text and Danger buttons and ListItem on both papers, Filled on black. This is deliberate, copied from the CSS, where only the ground transitions. It reads as a blink on each press.

The question for the owner: keep the design's transition, or let the ink follow the ground, as the card's words were made to in [B-56](B-56-card-press-words.md). If it changes, the moved cells are designed here and said so (D13).
