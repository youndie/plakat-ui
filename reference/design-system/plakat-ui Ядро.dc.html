Hover для desktop (инверсия рамки) — после решения по платформе-лидеру. Фото в Плакате — подставить CC0 в Направлениях, здесь — стенд-ин под растром. Имена событий зафиксированы для звука: stamp, release, engage, wedge-in, wedge-out, lever, underline, hatch, print, tear, telegram.
