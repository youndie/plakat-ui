PLAKAT-UI · АКЦЕНТ · plakat/print/raskat
РАСКАТ
Ирисовая печать: две краски на одном валике дают зернистый переход. В ките это единственное исключение из «нет градиентов» — одна фигура на экран. Переход не плавный: каждый пиксель — либо одна краска, либо другая, и плотность зерна сжата к линии перехода. Код — plakat-raskat.js, Compose — plakat-raskat.kt.
ПРАВИЛА
K1
Одна фигура на экран — круг, клин или прямоугольник в Плакате, заставке или Окне. В контролах, карточках и тексте — никогда.
K2
Две краски кита: киноварь → бумага, киноварь → чёрный, охра → киноварь, серо-синий → киноварь, чёрный → бумага. Третьей нет.
K3
Направление — по оси −17° или поперёк неё (73°). Линия перехода смещена: 30–70 % фигуры, жёсткость ≥ 6 — у раската есть шов, а не туман.
K4
Фактура — зерно, растр или штрих, одна на экран; шаг 1–4 dp, по seed фигуры. Без сглаживания и прозрачности: раскат — это печать, а не смесь.
K5
Текст на раскат не ставим: контраст меняется по фигуре. Смысла раскат не несёт — в градациях серого экран читается без него.
K6
Выключается токеном plakat/print/raskat → фигура краской A. Compose: AGSL-шейдер на API 33+, ниже — CPU один раз в Bitmap.

ТРИ ФАКТУРЫ
Одна формула, разный порог: краска B там, где профиль перехода выше порога фактуры. Зерно — шум с волокном вдоль хода валика; растр — точки 45° того же шага, что у фото; штрих — линии параллельно шву, толщина растёт к B. На экране — одна фактура.
Зерно · волокно 50 %
Растр · точки 45°, шаг 8 dp
Штрих · линии вдоль шва, −17°
ДВИЖЕНИЕ · ROLL · 320 МС · HARD-STOP
0 · плоская A
60 · B с края
150 · вкатывается
320 · стоп на шве
Событие roll: линия перехода едет от дальнего края до цели. Фактура при этом стоит на месте — двигается только краска, как на валике. Только при появлении Плаката; reduce motion — сразу финал.
ГДЕ ПРИМЕНЯЕМ
Плакат / Круг · раскат — композиция Ядра; круг-раскат киноварь → бумага по −17°, переход 58 %. Круг ушёл из-под заголовка (K5).
Заставка / Клин · раскат — клин на всю ширину, киноварь → чёрный поперёк оси: восход над землёй.
Окно / Панель · раскат — картинка онбординга: прямоугольник охра → киноварь, остальное плоско.
