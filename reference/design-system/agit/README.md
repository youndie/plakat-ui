# plakat-ui · как рисовать новую заготовку

Заготовка — абстрактная композиция для пустого состояния, заставки, онбординга или фона Плаката. В ките их шесть (`agit/preset-*.svg`), новые рисуются по правилам ниже. Если картинка нужна быстро и не обязана быть авторской — `generate(seed)` из `plakat-gen.js` соберёт её по тем же правилам.

## Формат

- Кадр кратен 8. Базовые: 360 × 240 (пустые состояния), 390 × 392 (Плакат «Круг»), 240 × 400 (вертикальная заставка).
- Один SVG: только `rect`, `circle`, `polygon`; `fill` — один из четырёх токенов (`paper`, `concrete`, `ink`, `red`). Без `stroke`, градиентов, прозрачности, фильтров, текста.
- Поворот — только `transform="rotate(-17 …)"` или 0° / 90°.
- Тёмная версия — те же фигуры, палитра `dark`: файл `*-dark.svg` рядом.

## Порядок работы

1. **Сначала зона заголовка.** Отступ 16 от края, ширина 45–60 % кадра, высота 26–40 %. Чёрные и красные фигуры в неё не заходят; серая плашка может лежать под ней.
2. **Одна крупная форма** — круг или клин. Она держит композицию.
3. **2–4 элемента из словаря:** круг, точка, брус 8 / 16 / 24, клин 17°, серая плашка, колонны, клетка, рельс с разрывом, полоса раппорта, земля (брус 8 по нижнему краю).
4. **Ровно один красный элемент**, не больше трети кадра. В группе (колонны, клетка, рельс) красной может быть одна часть.
5. **Одна ось −17°.** Брус лежит по оси или по сетке 0° / 90°; гипотенуза клина — 17°. Композицию с диагональю не зеркалить: зеркало даёт +17°.
6. **Сетка 8.** Координаты и размеры кратны 8; фигуры встают встык или с зазором 8.
7. **Стоит на земле.** Хотя бы одна фигура опирается на нижний край или на брус-землю. Парящие формы — это супрематизм, не наш регистр.
8. **За край — можно.** Круг-восход и брус могут уходить за кадр: композиция кажется шире экрана.

## Проверка перед сдачей

- В градациях серого красный элемент всё ещё главный.
- На 64 px читается силуэт.
- Заголовок Display (Rubik Mono One, ink) в зоне читается без плашки.
- Нет предметов, людей, букв, стрелок, звёзд и любой символики эпохи.
- Не перерисовка конкретного плаката, обложки или проуна.

## Не так

- Две красные фигуры или красный фон на весь кадр.
- Скругления, обводка, тень, градиент, полупрозрачность.
- Вторая диагональ (например, +17° рядом с −17°) или произвольный угол.
- Фигура заходит в зону заголовка «чуть-чуть».
- Раппорт под текстом.

## Программно

```js
import { generate, toSVG, PAL } from './plakat-gen.js';
const c = generate(article.id, { W: 360, H: 240 });   // { head, shapes, elements, red }
const svg = toSVG(c.shapes, c.W, c.H, PAL.light);
```

```kotlin
val c = PlakatGen.generate(seed = article.id.stableSeed(), w = 360.0, h = 240.0)
```

Seed берите из контента (id статьи, раздела), чтобы картинка не менялась между запусками.
